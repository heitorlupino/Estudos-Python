# Arquivos de Aula - Hashtag

Este repositório reúne os materiais de estudo e exercícios de Python do curso da Hashtag, organizados por módulos e aulas práticas.

## Objetivo

O projeto tem como finalidade registrar o aprendizado em lógica de programação, Python e estruturas de dados, com exemplos, exercícios e materiais de apoio.

## Estrutura do repositório

- `Módulo 3 - Lógica de Programação/` - fundamentos de lógica e programação.
- `Módulo 4 - Mais sobre Variáveis/` - tipos de variáveis, conversão e formatação.
- `Módulo 5 - If Condições em Python/` - estruturas condicionais e tomada de decisão.
- `Módulo 6 - Strings Textos e a importância no Python/` - manipulação de textos e strings.
- `Módulo 7 - Listas Python - Métodos e Usos/` - listas, índices, operações, ordenação e métodos.

## Tecnologias

- Python
- Jupyter Notebook
- VS Code

## Como usar

1. Clone o repositório.
2. Abra a pasta em um editor como VS Code.
3. Execute os arquivos `.py` ou abra os notebooks `.ipynb` para visualizar e praticar os exercícios.

## Observação

Este repositório foi organizado para estudo e prática pessoal, sendo útil como material de referência para acompanhar os módulos do curso.
